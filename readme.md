# Personal Expense Tracker

A mobile application built with React Native (Expo) for tracking personal expenses.

## Features
- Add, edit, and delete expenses
- View all expenses sorted by date
- Category-wise summary with charts
- Local storage with AsyncStorage

## Tech Stack
- React Native (Expo)
- React Navigation
- AsyncStorage
- Victory Native (Charts)

## Setup
npm install
npm start
